# Gate A Plan Review Checklist

Present this checklist in the plan handoff, pre-filled with counts. A human sets the manifest

review status to `Approved` only after every item is checked.

1. Every in-scope story appears; exclusions have named authority.
2. Criterion counts per story match the source (spot-check the largest story).
3. Obligation decomposition of compound criteria is sensible.
4. Personas per criterion match the spec's RBAC table, and `real`/`simulated` is visible.
5. Journey count per story is proportional to obligations — a uniform count across stories of different
   size must be justified.
6. Every non-`Covered` row has a distinct blocker, remediation and a real owner (not `TBD`).
7. Authority/implementation conflicts are listed with a decision or an owner.
